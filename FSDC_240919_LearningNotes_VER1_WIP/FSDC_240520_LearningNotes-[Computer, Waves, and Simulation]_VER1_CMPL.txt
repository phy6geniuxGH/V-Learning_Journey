	W5V2 - Fourier Series - Examples
	- How to use sin/cos functions to approximate the known function f(x)?

		a_k = 1/\pi \int^\pi_\pi f(x) cos(kx) dx k = 0,1,...,N
		b_k = 1/\pi \int^\pi_\pi f(x) sin(kx) dx k = 1,..., N

			- integrate:
					\int_D -\mu \partial^2_x u v dx = \int_D f v dx

	W6V3 - Solution Scheme
	- \sum^N_{i = 1} u_i \mu \int_D \partial_x \phi_i \partial_x \phi_j dx = \int_D f \ phi_j dx
			u = (u1 u2 ... uN).T
			f = (\int_D f \phi_1 dx  \int_D f \phi_2 dx  ...  \int_D f \phi_N dx) - forces acting on element boundaries
			K -> K_{ij} = \mu \int_D \partial_x \phi_i \partial_x \phi_j dx
	Discretized version:
		u_i K_{ij} = f_j 
			-> Linear system of N equations
			K^T u = F
			=> solution of the static Finite-Element problem

									N^2 (N = number of degrees of freedom)

									- structure of the stiffness matrix

	W8V3 - Element Level
	- Forward Mapping: x(\xi) = Fe(\xi) = x_e + h_e (\xi + 1)/2
		for \xi = -1, x(\xi) = x_e
		for \xi = 1, x(\xi) = x_e + h_e
	- Inverse Mapping
		\xi(x) = 2(x - x_e)/h_e - 1
		for x = x_e -> \xi(x_e) = -1
		for x = x_e + h_e -> \xi(x_e + h_e) = 1
	Integration with local coordinates
	 x -> \xi
	  \int_D_e f(x) dx -> \int_{-1}^{1} f(\xi) dx/d\xi d\xi (dx/d\xi) the Jacobian
	  Our Jacobian: dx/d\xi = h_e/2
	  Inverse Jacobian: d\xi/dx = 2/h_e

	W8V4 - lagrange interpolation
	- Function interpolation
		Limited area inside an element
		Lagrange Polynomials
			Gauss-Lobatto-Legendre Points - GLL points
		N is a simulation parameters
		Densification of grid points at boundaries can be problematic
			-> Courant Criterion
				Time step depends on the smallest distance
			-> too expensive
		In realistic simulations: N <= 4
			- 5 collocation points,
			- 4 distances

			u(x) = u_1 l_1^1 (xi) + u_2 l_2^2 (xi) + u_3 l_3^3 (xi)
				 = (u, E) = (2 , 1), (2, 3), (1, 0)
				 = u_0 [(E - E1)(E - E2) / (E0 - E1)(E0 - E2) ] +
				   u_1 [(E - E0)(E - E2) / (E1 - E0)(E1 - E2) ] +
				   u_2 [(E - E0)(E - E1) / (E2 - E0)(E2 - E1) ]
				 = 2 [(E - E1)(E - E2) / (E0 - E1)(E0 - E2) ] +
				   2 [(E - E0)(E - E2) / (E1 - E0)(E1 - E2) ] +
				   1 [(E - E0)(E - E1) / (E2 - E0)(E2 - E1) ]
				 = 2 [(E - 3)(E - 0) / (1 - 3)(1 - 0) ] +
				   2 [(E - 1)(E - 0) / (3 - 1)(3 - 0) ] +
				   1 [(E - 1)(E - 3) / (0 - 1)(0 - 3) ]
				 = (2E^2 - 6E)/(-2) +  (2E^2 - 2E)/6 + (E^2 - 4E + 3)/3
				 = -E^2 + 3E + (1/3)E^2 - (1/3)E + (1/3)E^2 - (4/3)E + 1
				 = -1/3 E^2 + 4/3 E + 1
				 = -1/3 (E^2 - 4E - 3)
